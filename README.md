# Tanner Lee Corley — Academic Website

Five pages: `index.html` (Home), `research.html`, `teaching.html`, `cv.html`, `about.html`.

## Preview
Double-click `index.html` to open it in a browser. Navigation works without installing anything.

## Edit
- Open any `.html` file in a text editor (VS Code is recommended). Edit the words between HTML tags, save, and refresh your browser.
- `styles.css` controls the shared design. Change the `:root` variables at the top to adjust colors and maximum width.
- The header and footer appear in each HTML file. If you change navigation, make the same change in all five files.
- Replace `assets/Tanner_Corley_CV.pdf` with an updated PDF **using the same filename** to update the CV page. The site uses the latest uploaded PDF; no Word version is included.
- Add a headshot later by placing it in `assets/` and adding an `<img>` tag to the homepage. No headshot is included yet.
- Teaching syllabi are placeholders until you choose which files to publish.

## Publish for free with GitHub Pages
1. Create a GitHub account and a new public repository named `yourusername.github.io`.
2. Upload all website files and the `assets` folder, preserving their structure.
3. Under repository Settings → Pages, choose Deploy from a branch, `main`, root `/`.
4. The site will appear at `https://yourusername.github.io/` after deployment.
5. To update, edit or replace files in the repository; changes publish automatically.

You can connect a purchased custom domain later via GitHub Pages settings and your registrar's DNS.

## Notes
This is a static site: no paid platform, tracking, analytics, cookies, or third-party fonts. Publication details are transcribed from the supplied CV; review before publishing.
